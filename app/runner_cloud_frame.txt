server — the connector named "AICortex" in this session. The user set up these jobs
for this runner in AICortex themselves; they are listed at the end of this message.

For EACH listed job, in order:

1. Carry out its `prompt`. Use the AICortex connector where the job needs it: its

   `integration_call`.

   arguments={"name": <id>, "result": <one-line summary>})`.

only on the listed ones. If a tool call fails, note it in the result and continue.
